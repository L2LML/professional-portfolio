Accept money

Sell a product

Look a slot code up in inventory, and walk through every failure mode in order — invalid code, sold out, insufficient funds — before dispensing and printing the flavor message.

VendingMachine.java
Concepts Helper methods, .equals() vs. == for object comparison, BigDecimal.compareTo()
7

Make change

Greedy coin algorithm — as many quarters as fit, then dimes, then nickels — returning the fewest coins possible, then resetting the balance to zero.

VendingMachine.java
Concepts Integer division vs. modulo, arrays for returning multiple values
↻

Refactor, ahead of testing

Coin math started out as a private method buried inside VendingMachine — fine to run, impossible to unit test directly. Pulled it out into its own ChangeCalculator class with a public method, matching the capstone's own guidance to keep classes testable and console I/O contained. Same logic, now independently verifiable.

Audit every transaction

AuditLogger.java
Concepts Append-mode file writing, DateTimeFormatter, fixed-scale currency formatting
